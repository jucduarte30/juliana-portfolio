Systems Programming — C

Distributed Key-Value Store with Chain Replication

Distributed Systems & Operating Systems coursework, FCUL

A DynamoDB-style key-value store built in C across four progressive phases: core data structures and serialization, a client-server RPC layer using Protocol Buffers, a multi-threaded concurrent server synchronized with mutexes and condition variables, and finally fault-tolerant replication using the Chain Replication model, coordinated through Apache ZooKeeper. A companion Operating Systems project (a multi-process hospital admissions simulator) added shared memory, semaphores, and POSIX signal handling to the same skill set.
